# Confusion Matrices and Classification Metrics

A set of worked exercises for calculating and visualizing classification metrics from binary and multiclass confusion matrices, including examples for spam detection and imbalanced classification.

## Workflow

1. Define confusion-matrix counts for each problem.
2. Calculate accuracy, precision, recall, sensitivity, specificity, F1, and false-positive rate.
3. Visualize confusion matrices and metric comparisons.
4. Compare example models and discuss class imbalance.

## Data Requirements

- No external dataset is required; confusion-matrix values are embedded in the notebook.

Datasets and generated artifacts are not included unless they are embedded directly in the notebook.

## Requirements

- NumPy
- Matplotlib

Install missing packages in your Jupyter or Google Colab environment before running the notebook.

## Running the Notebook

1. Open [`Confusionmatrixpart1.ipynb`](Confusionmatrixpart1.ipynb) in Jupyter Notebook or Google Colab.
2. Place any required data files in the path expected by the notebook.
3. Update local or Google Drive paths where needed.
4. Run the cells from top to bottom.

## Outputs

- Calculated classification metrics
- Binary and multiclass confusion-matrix plots
- Metric comparison charts
